Technical Lessons Learnt

Stack-level traps hit while building a multi-tenant Next.js / TypeScript front end on a FastAPI / Python back end with PostgreSQL and MongoDB. Each lesson gives the symptom that shows up, the root cause, how it was resolved, how to prevent it, and a detection recipe you can automate. Most of these came from incidents in a production multi-tenant codebase's commit history, docs and task records; others are well-known traps from vendor documentation and OWASP. The evidence and sources fields tell you which.

Machine-readable. Everything on this page is rendered from technical-lessons-learnt.json. That file is the canonical catalogue: edit it, not this page. The Markdown rule packs in rules/ are generated from it with python3 docs/lessons/export_lessons_learnt.py --out docs/lessons/rules. Serve this folder over HTTP to view the page (python3 -m http.server -d docs/lessons); opened from file://, browsers block the JSON fetch. Detection regexes are starting points; every one produces false positives, so tune it for your repository before you gate on it.
